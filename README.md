**LiveFrame** - полноценный анимационный движок для
[Voxel Core](https://github.com/MihailRis/voxelcore/tree/main), написанный на **Lua**, с
собственным форматом анимаций **LFA**, поддержкой аниматоров и простых проигрывателей анимаций, а также удобным
**API** для контент-паков. Документация [здесь](docs/ru/public/README.md).

> [!WARNING]
> Поскольку проект ещё находится в стадии формирования, некоторые его части
> могут быть существенно изменены к релизу и быть сломана обратная
> совместимость, поэтому, рекомендую дождаться полноценного релиза перед
> использованием проекта.

## Связанные проекты

- [**LiveFrame-BBPlugin**](https://github.com/Onran0/LiveFrame-BBPlugin) - плагин для **Blockbench**,
позволяющий экспортировать анимации в **LFA**.
