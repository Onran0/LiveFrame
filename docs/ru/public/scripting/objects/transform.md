# Объект transform

**Описание**

Используется для хранения трансформаций (позы) кости или чего-то другого.

**Структура**

> [!NOTE]
> `*` слева от названия свойства означает, что оно опционально.

```lua
transform = {
    *[1] = { x, y, z }, -- позиция в vec3
    *[2] = { w, x, y, z }, -- вращение в quat
    *[3] = { x, y, z } -- масштаб в vec3
}
```
