# Объект model_metadata

**Описание**

Используется для хранения данных об уже загруженной модели и её скелете.

**Структура**

> [!NOTE]
> `*` слева от названия свойства означает, что оно опционально.

```lua
model_metadata = {
    -- имя скелета
    skeleton: string,

    -- имена под-моделей (мешей)
    meshes: table<string>,
    
    -- информация о костях скелета
    bones: table = {
        ["имя кости"] = {
            -- индекс меша, соответствующего этой кости
            *mesh: int,
        
            -- матрица для кости по-умолчанию
            matrix: mat4
        },
        ...
    }
}
```
