# Объект clips_file_data

**Описание**

Используется для хранения информации о файле с клипами, например, его путь или специфические настройки.

**Структура**

> [!NOTE]
> `*` слева от названия свойства означает, что оно опционально.

```lua
clips_file_data = {
    -- путь к файлу с клипами
    path: string,
    
    -- таблица, позволяющая переопределить названия некоторых клипов из файла
    *overrides: table<string=string> = {
        ["старое_имя_клипа"] = "новое_имя_клипа",
        ...
    },

    -- таблица, позволяющая определить некоторые, возможно специфические
    -- параметры для загрузки этого файла. (см ../../load_settings.md)
    *loadSettings: table
}
```
