# Компонент liveframe:model

Этот компонент используется для загрузки 3D-модели на сущность.

> [!NOTE]
> Могут быть ситуации, когда нужно использовать одновременно и модель, и анимации
> с одного или разных файлов.\
> В таких случаях нужно загружать модель раньше, чем анимации, т.е. в случае
> компонентов определить компонент `liveframe:model` первее, чтобы на момент
> загрузки анимаций скелет уже был загружен. Иначе вы получите сломанную анимацию.

## Аргументы компонента

- `path` - путь к файлу модели;
- `load-settings` - настройки загрузки модели.

Также поддерживается одиночный ввод строки с путём напрямую в `args` для удобства и краткости.

Примеры:

```json
{
    "name": "liveframe:model",
    "args": "packid:models/workbench.glb"
}
```

```json
{
    "name": "liveframe:model",
    "args": {
        "path": "packid:models/workbench.glb",
        "load-settings": {
            "scene": 2
        }
    }
}
```
