# LFA

<sup>[**Плагин для Blockbench для экспорта анимаций в LFA**](https://github.com/Onran0/LiveFrame-BBPlugin)</sup>

**LFA** (LiveFrame Animation) - текстовый формат
описания анимаций для скелетов **VoxelCore**, использующийся
контент-паком **LiveFrame**.

Формат старается быть похожим на **VCM** для удобства
и большего сходства с движком.

Формат описания элементов и иерархии почти такой же, как и в
**VCM**:

```
@элемент атрибут ( значение1, значение2,... ) атрибут2 "значение3" атрибут3 ( ключ1: значение1, ключ2: значение2, ... ) {
    @внутренний_элемент_1 ...
    @внутренний_элемент_2 ...
}
```

> [!NOTE]
> Звёздочка (`*`) слева от названия атрибута/поля означает, что он - опционален.

## Основные элементы

### Элемент `metadata`

***Описание***

Используется для описания метаданных файла и других элементов.

> [!NOTE]
> Обязателен.

***Атрибуты***

- `version` - версия формата *LFA* файла вида `major.minor`. Актуальное значение: `1.0`;\


- `*euler-order` - порядок вращения углов Эйлера
  для всех элементов в файле.\
  Значение по-умолчанию: `xyz`.


- `*relativize-keys` - булев или массив, определяющий, должны ли
все/часть представленных в клипах трансформаций релятивизироваться
относительно начальной позы в `skeleton`. Настройка была создана
в том числе для `VCM`, загрузчик которого вращает вершины костей
при загрузке модели. Однако для прямого риггинга это может быть
нежелательно.\

`true` - означает релятивизировать все каналы;\
`false` - означает не релятивизировать никакой из каналов;\
Также можно выбрать отдельные каналы с помощью массива, которые должны
релятивизироваться, перечислив строковые идентификаторы каналов
`position`, `rotation` и `scale`.\
Значение по-умолчанию: `true`

***Пример***

```
@metadata version 1.0 relativize-keys ( "position" )
```

### Элемент `skeleton`

***Описание***

Используется для описания скелета, трансформируемого клипами, а также для определения начальной позы.

> [!NOTE]
> Может быть определён только единожды на весь файл.

> [!WARNING]
> Все кости использующиеся в клипах обязательно должны быть определены в `@skeleton`!

***Допустимые вложенные элементы***

`skeleton#bone`.

***Пример***

```
@skeleton {
    @bone name "head" rotation (0, 0, 0)
    @bone name "left_arm" rotation (0, 0, 0) position (0, 0, 0)
    @bone name "right_arm" rotation (0, 0, 0) position (0, 0, 0)
}
```

### Под-элемент `skeleton#bone`

***Описание***

Используется для описания конкретной кости скелета, а также для её начальной позы.

> [!NOTE]
> Ввиду устройства скелетов в **VoxelCore**, в описании отсутствует иерархия, а также
> все кости должны иметь уникальное название. То-есть, описание скелета с двумя костями
> с названием, например, `head`, будет считаться невалидным.

***Атрибуты***

- `name` - имя кости;
- `*position` - начальная позиция кости в формате `(x, y, z)`. Значение по-умолчанию: `(0, 0, 0)`;
- `*rotation` - начальная позиция кости в формате `(x, y, z)` для
углов Эйлера, или `(x, y, z, w)` для кватернионов. Значение по-умолчанию:
`(0, 0, 0)` в углах Эйлера, или `(0, 0, 0, 1)` в кватернионе;
- `*scale` - начальная позиция кости в формате `(x, y, z)`. Значение по-умолчанию: `(1, 1, 1)`.

***Пример***

```
... {
    @bone name "head" rotation (0, 0, 0)
    @bone name "left_arm" rotation (0, 0, 0) position (0, 0, 0)
    @bone name "right_arm" rotation (0, 0, 0) position (0, 0, 0)
}
```

### Элемент `clip`

***Описание***

Используется для описания конкретного клипа анимации.

***Атрибуты***

- `name` - название клипа;


- `*loop` - булев, определяющий, может ли клип быть
зациклен.\
Значение по-умолчанию: `false`;


- `*duration` - длительность клипа в секундах. Если
не указано явно, то вычисляется автоматически на основе
времени последнего ключ-кадра.

***Допустимые вложенные элементы***

`keyframe`.

***Пример***

```
@clip name "test" loop true {
    ...
}
```

### Элемент `keyframe`

***Описание***

Используется для описания ключ-кадров в анимации. В описание входит:
- позиции, вращения и масштабы костей;
- время ключ-кадра;
- триггеры.

***Атрибуты***

- `time` - положительное время ключ-кадра в секундах;
- `time-add` - положительное число, с помощью которого
будет сформировано время текущего ключ-кадра путём сложения с временем предыдущего ключ-кадра.

> [!NOTE]
> Спецификация запрещает использовать `time` и `time-add` одновременно в одном ключ-кадре.
> Используйте их отдельно.

***Допустимые вложенные элементы***

`event`;\
`scope`;\
`bone`.

***Пример***

```
... {
    @keyframe time 0 {
        ...
    }
    
    @keyframe time-add 1 {
        ...
    }
}
```

> [!NOTE]
> Список ключ-кадров в `animation` должен быть отсортирован в порядке возрастания времени.

### Элемент `event`

***Описание***

Используется для оповещения скриптинга о начале конкретного
ключ-кадра и опционально для передачи константного значения.

***Атрибуты***

- `name` - название триггера;
- `*value` - (опционально) значение триггера. может быть строкой, булевом, числом или одномерным
массивом, состоящего из любых предыдуще перечисленных типов.

***Пример***

```
... {
    ... {
        @event name "speed" value 2
        
        ...
    }

    ... {
        @event name "attack"
        
        ...
    }
    
    ... {
        @event name "speed" value 1
        
        ...
    }
}
```

### Элемент `bone`

***Описание***

Используется для описания трансформаций конкретной кости
на текущем ключ-кадре.

***Атрибуты***

- `name` - имя кости;


***Допустимые вложенные элементы***

`position`;\
`rotation`;\
`scale `.

***Пример***

```
... {
    ... {
        ...
        
        @bone name "spine" {
            ...
        }
        
        @bone name "head" {
            ...
        }
    }
}
```

### Элемент `scope`

***Описание***

Используется для обобщения интерполяционных параметров каналов костей.

***Атрибуты***

- `interp` - используется для определения идентификаторов/типов выходных интерполяций
по-умолчанию для конкретных каналов дочерних элементов.\
Допустимые ключи:
- - `*position` - идентификатор/тип выходной интерполяции для позиции по-умолчанию.\
Стандартные типы: `lerp`; `cubic-spline`; `step`, по-умолчанию: `lerp`;
- - `*rotation` - идентификатор/тип выходной интерполяции для вращения по-умолчанию.\
    Стандартные типы: `nlerp`; `slerp`; `squad`; `step`, по-умолчанию: `nlerp`;
- - `*scale` - идентификатор/тип выходной интерполяции для масштаба по-умолчанию.\
    Стандартные типы: `lerp`; `cubic-spline`; `step`, по-умолчанию: `lerp`.

> [!NOTE]
> Касательные (тангенсы) для `cubic-spline` вычисляются автоматически.
> Для ручной настройки смотрите документацию об элементе `interp`.

> [!NOTE]
> Контрольные кватернионы для `squad` вычисляются автоматически.
> Для ручной настройки смотрите документацию об элементе `interp`.

> [!NOTE]
> Идентификатор интерполяции означает идентификатор кастомной
> конкретизации какого-либо типа интерполяции (см. элемент `interp`).

> [!NOTE]
> При умолчании идентификатора/типа интерполяции для канала, явно указанное
> значение будет искаться вверх по иерархии (т.е. от родителя к родителю
> родителя и т.д.), пока не найдётся явно указанное значение. Значение по-умолчанию
> будет использовано только если явно указанное значение не было найдено.
> Если же говорить кратче, то приоритет выбора значения такой:
> `transformation (position, rotation, scale) > scope's > default`

***Допустимые вложенные элементы***

`scope`;\
`bone `.

***Пример***

```
... {
    ... {
        @scope interp ( position: "lerp" ) {
            ...
            
            @scope interp ( position: "cubic-spline", rotation: "slerp" ) {
                ...
            }
        }
    }
}
```

### Элемент `position`

***Атрибуты***

- `value` - массив вида `(x, y, z)`, представляющий позицию;
- `*interp` - идентификатор/тип выходной интерполяции для канала.

***Пример***

```
... {
    ... {
        ... {
            @position value (0, 0, 0)
        }
    
        ... {
            @position value (0, 2, 2) interp "lerp"
        }
        
        ... {
            @position value (0, 4, 4) interp "cubic-spline"
        }
    }
}
```

### Элемент `rotation`

***Атрибуты***

- `value` - вращение, представленное углами Эйлера в градусах (массив вида `(x, y, z)`),
или кватернионом (массив вида `(x, y, z, w)`);
- `*interp` - идентификатор/тип выходной интерполяции для канала.

***Пример***

```
... {
    @scope interp ( rotation: "slerp" ) {
        ... {
            @rotation value (0, 0, 0, 1) interp "squad"
        }
    
        ... {
            @rotation value (90, 90, 90) interp "nlerp"
        }
    }
}
```

### Элемент `scale`

***Атрибуты***

- `value` - массив вида `(x, y, z)`, представляющий масштаб;
- `*interp` - идентификатор/тип выходной интерполяции для канала.

***Пример***

```
... {
    ... {
        ... {
            @scale value (0, 0, 0)
        }
    
        ... {
            @scale value (0, 2, 2) interp "lerp"
        }
    }
}
```

## Элементы для сложной анимации

### Элемент `interp`

***Описание***

Используется для конкретизации параметров для некоторых видов интерполяций (в т.ч. `cubic-spline`, `squad`)

***Атрибуты***

- `id` - идентификатор конкретизированной интерполяции, который можно будет использовать в анимациях;
- `type` - тип конкретизируемой интерполяции. Доступные значения: `cubic-spline`; `squad`;
- `*target` - тип данных, к которым применяется интерполяция. Доступные значения: `vec3`, `quat`.\
Если значение не указано явно, то будет использовано значение по-умолчанию в зависимости от типа интерполяции.

Таблица применимости интерполяций к типам:

| Тип            | Применима к    | `target` по-умолчанию |
|----------------|----------------|-----------------------|
| `cubic-spline` | `vec3`; `quat` | `vec3`                |
| `squad`        | `quat`         | `quat`                |


***Поля***

Для описания параметров различных видов интерполяций, используется под-элемент `field`,
имеющий атрибуты `name` и `value`, которые содержат имя и значение параметра.

**Поля для `cubic-spline`**

- `start-tangent` - вектор, описывающий направление и скорость изменения значения (в ед/с) при выходе из текущего ключ-кадра;
- `end-tangent` - вектор, описывающий направление и скорость изменения значения (в ед/с) при входе в следующий ключ-кадр.

***Примеры***

**Для позиции и масштаба:**
```
@interp id "custom-interp" type "cubic-spline" target "vec3" {
    @field name "start-tangent" value (3,3,1)
    @field name "end-tangent" value (0,3,1)
}
```

**Для вращения:**
```
@interp id "custom-interp" type "cubic-spline" target "quat" {
    @field name "start-tangent" value (0,0.5,0,0.5)
    @field name "end-tangent" value (0.25,0.25,0.25,0.25)
}
```

**Поля для `squad`**

- `start-control` - контрольный кватернион, определяющий кривизну траектории при выходе из текущего ключ-кадра;

- `end-control` - вспомогательный кватернион, определяющий кривизну траектории при входе в следующий ключ-кадр;

***Пример***

```
@interp id "custom-interp" type "squad" {
    @field name "start-control" value (0,0.5,0,0.5)
    @field name "end-control" value (0.25,0.25,0.25,0.25)
}
```

### Под-элемент `interp#field`

***Описание***

Используется для описания конкретного поля интерполяции.

***Атрибуты***

- `name` - название поля;
- `value` - значение поля.

***Пример***

```
... {
    @field name "start-tangent" value (3,3,1)
    @field name "end-tangent" value (0,3,1)
}
```
