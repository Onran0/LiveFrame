# glTF

**LiveFrame** поддерживает загрузку **glTF** и **glB** файлов, реализуя большую часть спецификации [glTF 2.0](https://registry.khronos.org/glTF/specs/2.0/glTF-2.0.html).\
Однако не всю, и есть некоторые ограничения, или нюансы конвертации объектов во внутренние представления
**LiveFrame**, а также поддерживаемые расширения.\
Здесь это и будет расписано.

## Поддерживаемые расширения

На данный момент никакие расширения для **glTF** не поддерживаются. 
Вы можете написать предложения в **Issues** или ветке проекта.

## Ограничения реализации

Из-за отсутствия некоторых технических возможностей в **VoxelCore**, некоторые части спецификации полностью
не поддерживаются, или лишь частично.

### Изображения

Поддерживаются только **PNG**. Спецификация **glTF 2.0** также допускает **JPEG** изображения, однако конкретно
эта реализация на данный момент их не поддерживает.

Рассматривается возможность реализации декодера **JPEG** напрямую в **LiveFrame** с помощью возможностей канвасов.

### Сэмплеры текстур

Не поддерживаются, поскольку `assets.load_texture` позволяет указать лишь имя текстуры, формат и ее данные.
**VoxelCore** использует внутренние фиксированные настройки сэмплирования, что на момент написания этой
документации эквивалентны следующему **glTF** сэмплеру:
```json
{
    "samplers": [
        {
            "magFilter": 9728,
            "minFilter": 9728,
            "wrapS": 10497,
            "wrapT": 10497
        }
    ]
}
```
### Материалы

Поддерживается лишь `baseColorTexture`, так как в **VoxelCore** даже нет системы материалов и достаточных
инструментов для написания собственного подобного шейдера.

### Морф-таргеты и скиннинг

Поддержка полностью отсутствует, так как сам **VoxelCore** не поддерживает эти технологии.

> [!WARNING]
> Такие модели будут неправильно отображены или анимированы. Обратите на это внимание

## Внутренние представления

### Релятивизация

По-умолчанию для **glTF** моделей релятивизируется только позиция, а вращение и масштаб остаются
абсолютными и задаются через матрицы трансформации.
